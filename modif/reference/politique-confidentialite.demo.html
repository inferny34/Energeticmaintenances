Politique de confidentialité

Page de raccordement pour cet aperçu. Votre développeur doit relier ici la politique de confidentialité validée du site avant d’activer les formulaires.

Dans la configuration livrée, aucune demande ni pièce jointe n’est envoyée et les champs ne sont pas enregistrés dans le stockage du navigateur.

Pour le site définitif, la notice doit couvrir séparément les données des apporteurs, les clients présentés, les pièces bancaires et professionnelles, les destinataires, les durées, les droits, les bases légales et les modalités de transmission. L’article 8 du contrat V8 est fourni comme référence, sans remplacer cette politique.
